이 글은 자리를 잡아두려고 쓴 샘플입니다. 내용을 지우고 쓰셔도 되고,
폴더째 지우셔도 됩니다.

## 글은 어디에 두나

`content/` 아래에 **카테고리 폴더**를 만들고, 그 안에 **글 폴더**를 만듭니다.
글 폴더 안의 `index.md` 가 본문입니다.

```
content/
  네트워크/
    2026-09-05-hello-world/
      index.md
      thumbnail.png     ← 있으면 목록 카드 오른쪽에 나옵니다
```

카테고리는 프론트매터에 쓰지 않습니다. **폴더 경로가 곧 카테고리**입니다.
중첩하면 목록에 `프로그래밍 / 네트워크` 처럼 이어 붙여 나옵니다.

```
content/프로그래밍/네트워크/cors/index.md   →   프로그래밍 / 네트워크
```

## 프론트매터

네 가지만 있으면 됩니다.

| 키 | 필수 | 설명 |
| --- | --- | --- |
| `title` | 예 | 120자 이내 |
| `description` | 예 | 목록 카드의 요약이자 검색 결과에 나오는 문장. 300자 이내 |
| `date` | 예 | `2026-09-05` |
| `thumbnail` | 아니오 | 글 폴더 기준 상대 경로 |
| `draft` | 아니오 | `true` 면 `pnpm dev` 에서만 보입니다 |

값이 빠지거나 형식이 틀리면 **배포되지 않고 빌드가 실패합니다.** 잘못된 글이
조용히 올라가는 것보다 낫기 때문에 일부러 이렇게 두었습니다.

## 주소는 어떻게 정해지나

글 폴더 이름에서 앞의 날짜를 뗀 부분이 주소가 됩니다.

```
content/네트워크/2026-09-05-hello-world/  →  /posts/hello-world/
```

날짜 접두사는 파일 탐색기에서 순서대로 보려고 붙이는 것이라 선택입니다.
붙이지 않으면 폴더 이름이 그대로 주소가 됩니다.

## 발행

`main` 에 push 하면 GitHub Actions 가 빌드해서 올립니다. 그 외에 할 일은 없습니다.
