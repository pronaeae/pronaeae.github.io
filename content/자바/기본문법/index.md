## 기본 작성법

```
public class Example{
    public static void main(String[] arge){}
}
```

class는 클래스명 앞은 대문자로.

## 형

- byte (정수 표시)
- int (정수 표시)
- long (정수 표시)
- double (실수 표시)
- boolean (true / false 표시)
- String (문자 표시)

실무에서 사용하는 건 아마 이 정도 이지 않을까?

## 연산자

- ==
- <
- >
- !=
- ||
- &&
- !
- > =
- <=
